# Сердце практики Дхаммы

Конспект по раннесуттовой Дхамме: карта, воркбук и словарь палийских терминов.

Страница документа: https://salistamba.github.io/serdtse-praktiki-dhammy/

PDF: https://salistamba.github.io/serdtse-praktiki-dhammy/serdtse_praktiki_dhammy.pdf

English version: https://salistamba.github.io/the-heart-of-dhamma-practice/

Содержит основные темы практики: четыре `ariyasacca`, восьмеричный путь, пять предписаний, `sīla`, `sati`, `satipaṭṭhāna`, `samādhi`, джханы и `arūpa-āyatana`, `paṭiccasamuppāda`, `anattā`, `dukkha`, `taṇhā`, `upādāna`, `bhava`, `saṅkhārā`, `papañca`, пять `khandhā`, шесть сфер опыта, `nirodha` и `Nibbāna`, а также практические способы распознавания цепляния в повседневной жизни.

Этот текст не претендует на окончательность или безошибочность, является рабочей картой для сверки, практики и дальнейшего уточнения.
Не является медицинской, психологической или психотерапевтической рекомендацией.

В конце находятся словарь и ссылки на источники, которые использовались при формировании.
